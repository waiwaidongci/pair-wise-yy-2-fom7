# 赛鸽血统环号登记站

运行：

```bash
npm start
```

访问`http://localhost:3024`。支持档案、血统查询、转让、归巢成绩和失鸽找回认领。

## 失鸽找回认领流程

- 拾获登记即立案：提交足环号、现鸽主（拾获保管人）、认领人和见证材料。一只鸽只挂一笔未结认领；两人同时提交时，后来者只拿到首案编号。
- 结案前该鸽暂停转让与比赛报名；往期名次仍归比赛当天鸽主（成绩按当天鸽主存档）。
- 现鸽主与认领人双方确认后结案，新归属生效并自动记一笔“认领结案”转让。
- 认领人撤回或父母档案改动会触发作废重判：重判成立则案卷作废；不成立则回滚到首案状态。作废后再次提交沿用首案编号重新开庭。

## 模块

- `claims.js`：认领裁决（立案、双方确认结案、撤回、作废重判与回滚）。
- `store.js`：档案保存（JSON 文件读写与种子数据）。
- `page.js`：页面入口（单页 HTML）。
- `server.js`：HTTP 路由，串联以上模块；请求串行写盘。
